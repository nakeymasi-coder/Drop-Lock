# The Lock Drop

Interactive Bold Streetwear locksmith homepage concept for remodels and renovations, serving the Elkhart And South Bend Area.

## Preview status

This is a **design/demo site**, not an operational locksmith booking service. Business name, tagline, offer terms, actual service availability, verified reviews, and contact form delivery must be supplied and confirmed before commercial launch. The form validates input but **does not submit requests**.

Open `index.html` directly or view the GitHub Pages deployment when enabled.
